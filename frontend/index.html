Sobre o projeto

Uma nova forma de conectar clientes e fotógrafos.

Encontrar um fotógrafo adequado para um evento pode ser uma tarefa difícil. Muitas vezes, clientes precisam procurar profissionais em diferentes redes sociais, comparar informações manualmente e entrar em contato individualmente com cada fotógrafo.

A FocoConecta propõe centralizar esse processo em uma única plataforma, reunindo informações sobre profissionais, serviços, preços, disponibilidade e trabalhos realizados.

Perguntas frequentes

Conheça melhor a FocoConecta.

O que é a FocoConecta?

A FocoConecta é uma plataforma web criada para conectar fotógrafos de eventos a clientes que buscam serviços fotográficos.

Como os clientes encontram fotógrafos?

Os clientes podem pesquisar profissionais, comparar serviços, consultar informações, visualizar portfólios e verificar a disponibilidade dos fotógrafos.

Quais funcionalidades a plataforma oferece?

A plataforma oferece cadastro e autenticação de usuários, busca de fotógrafos, visualização de portfólios, consulta de serviços e preços, disponibilidade e solicitações de orçamento.

Quais tecnologias serão utilizadas no projeto?

O projeto utiliza tecnologias como React, Python e serviços da AWS, incluindo Amazon S3, AWS Lambda, API Gateway, DynamoDB, Amazon Cognito e CloudFront.
